# Skill Router

Use this router before starting any task. Always also follow root `AGENTS.md`.

## Routing rules

| Task includes                                  | Load                                |
| ---------------------------------------------- | ----------------------------------- |
| Creating/updating a landing section            | `section_build.md`, `build-page.md` |
| Adding a new route or page                     | `build-page.md`                     |
| Images, icons, backgrounds, asset paths        | `assets.md`                         |
| Figma links/IDs, design-to-code work           | `assets.md`, `section_build.md`     |
| Desktop/tablet/mobile checks                   | `responsive_check.md`               |
| Branch review, PR review                       | `code_review.md`                    |
| Creating branches/PRs, writing PR descriptions | `pr_workflow.md`                    |
| Final QA before merge                          | `qa-checklist.md`                   |

If a task touches multiple areas, combine skills.

## Examples

- New section from Figma: `assets.md` + `section_build.md` + `responsive_check.md`.
- Asset migration: `assets.md` + `pr_workflow.md`.
- Pre-merge review: `code_review.md` + `responsive_check.md` + `qa-checklist.md`.
